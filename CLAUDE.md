## What it is

Native iOS app for someone who works on their own vehicles **and** does paid work on other people's. Tracks every vehicle, every service, every part, every dollar. Generates professional quotes and PDF service records for customers. Built for the one-person shop, mobile mechanic, side-hustle wrench, and serious enthusiast — not big shops.

**Wedge:** iPhone-first, beautiful UI, $30/mo instead of $300/mo, motorcycles treated as first-class, customer-ready PDFs.

## Tech stack

- **SwiftUI** + iOS 17.0 minimum (for `@Observable`)
- **SwiftData** with **CloudKit** sync
- **VisionKit** (DataScannerViewController) — VIN scan + receipt OCR
- **PencilKit** — signature capture
- **PDFKit** — export generation
- **Swift Charts** — reports
- **UserNotifications** + **BackgroundTasks** — reminders
- **StoreKit 2** (wrapped behind a `StoreService` protocol; RevenueCat later)
- iPhone only (`TARGETED_DEVICE_FAMILY = 1`)

## Conventions

- **MVVM with `@Observable`**. ViewModels are `@MainActor final class`. UI-readable state is `private(set) var`.
- **Services behind protocols.** Every system-touching service has a `protocol Foo` + real impl + `InMemory…` fake.
- **Theme tokens only.** Never use raw color literals in views. Always `Color.bgPrimary`, `Color.accentPrimary`, etc.
- **Spacing scale:** `Spacing.xs/s/m/l/xl/xxl` only. No literal `.padding(16)` in views.
- **No force unwraps in production code.** Tests can `try!` freely.
- **Money:** persist as `Double`. Compute with `Decimal` at the call site. Display via `Money.format`.
- **CloudKit-safe SwiftData:** every property has a default OR is optional; no `.unique`; relationships optional; `@Attribute(.externalStorage)` for image `Data`.
- **No SPM dependencies** without explicit justification. Stock iOS SDK only for v1.

## Build / test commands

```bash
# Regenerate Xcode project from project.yml
xcodegen generate

# Sim build (Debug)
xcodebuild -project GarageTime.xcodeproj -scheme GarageTime \
  -destination 'platform=iOS Simulator,name=iPhone 17 Pro' \
  -configuration Debug build

# Run tests
xcodebuild -project GarageTime.xcodeproj -scheme GarageTime \
  -destination 'platform=iOS Simulator,name=iPhone 17 Pro' test

# Archive (release)
xcodebuild -project GarageTime.xcodeproj -scheme GarageTime \
  -destination 'generic/platform=iOS' \
  -archivePath build/GarageTime.xcarchive archive
```
